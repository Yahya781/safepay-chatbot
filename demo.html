SafePay Chat Widget

Add a professional AI chatbot to any website with a single line of code.

Quick Start

Add this single line anywhere in your HTML (before the closing </body> tag):

<!-- SafePay Assistant Widget --> <script src="http://127.0.0.1:8000/widget.js" async></script>
💡 The widget will appear as a floating chat bubble in the bottom-right corner. It auto-opens after 3 seconds. Click the bubble to open/close the chat panel.

Configuration Options

Customize the widget using data-* attributes:

<script src="http://127.0.0.1:8000/widget.js" data-api="https://your-api-server.com" <!-- API base URL (auto-detected if omitted) --> data-position="bottom-right" <!-- "bottom-right" or "bottom-left" --> data-auto-open="false" <!-- Disable auto-open (default: true) --> async ></script>

How It Works

The widget is made of two parts:

  • widget.js — Injects a floating chat bubble and an iframe into the page.
  • widget.html — The chat UI loaded inside the iframe (fully CSS-isolated from the host page).

The iframe communicates with your FastAPI backend's /ask endpoint via CORS-enabled fetch requests.
